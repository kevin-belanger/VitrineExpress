# VitrineExpress

Application web d'affichage numérique : diffusion de messages (images, textes) sur des téléviseurs regroupés par groupes.

- PHP 8.1+
- SQLite
- Page d'affichage en JavaScript simple (compatible avec les navigateurs de télé)

Spécifications du MVP : [docs/specification-mvp.md](docs/specification-mvp.md)
